==========================================
  캡컷 올인원 — 사용법
  made by 바람님 (with Claude Code)
==========================================

모든 파일은  바탕화면\캡컷 올인원 효과 프로그램\  안에 있습니다.


전체 흐름 (3단계)
------------------------------------------
  원본.zip
    → ① 시작하기.bat
    → ② 인트로_넣기.bat
    → ③ 마지막_여운주기.bat
    → 캡컷으로 불러오기

  ②③ 은 필요할 때만 쓰시면 됩니다. 순서만 지키면 돼요.
  챕터 제목은 ① 안의 [챕터] 탭에서 같이 넣습니다.
  인트로가 없는 영상이면 ① 만 돌리고 바로 캡컷으로 가셔도 됩니다.


------------------------------------------
① 효과 넣기 — 시작하기.bat
------------------------------------------
더블클릭 → 프로그램 창이 뜹니다.

 1. [기본] 탭 → [📁 캡컷 프로젝트 zip 선택] → 원본 zip 선택
    ⚠ [완성] 이 붙은 파일 말고 원본을 넣으세요. 효과가 이중으로 들어갑니다.
 2. 맨 아래 [✨ 효과 넣기 실행]
    → 같은 폴더에 "[완성] 원본이름.zip" 생성

★ 유료 효과는 이미 다 빼놨습니다 (2026-09-10 기준)
   아래 6개는 캡컷에서 💎 로 확인된 유료라서 "유료" 표시 + 사용 해제 했습니다.
   [효과] 탭의 "무료 효과만 사용"도 기본으로 켜져 있습니다.

     전환   세우기         ← 프로그램에 "푸시 확대" 로 들어있던 것
     전환   겹치기         ← 프로그램에 "오버레이 전환" 으로 들어있던 것
     전환   스크린 교체
     전환   스티커 메모
     전환   플로트 어웨이
     필터   명확한 ll

   ⚠ 세우기·겹치기는 캡컷이 이름을 바꾼 효과입니다. 그래서 예전에는
     프로그램 목록에서 다른 이름으로 보여 유료인 줄 몰랐던 겁니다.
     지금은 캡컷 화면에 뜨는 이름으로 맞춰놨습니다.

   화면효과 중 유료 9개(눈꽃·반짝반짝 3·벽난로·비네트·트윙클 더스트·
   노이즈 2·비네트 그레인·비·몽환 색종이)도 함께 해제했습니다.

   → 지금 쓰이는 것: 전환 7개 / 필터 0개 / 화면효과 15개
   → 나중에 유료 결제를 하면 [효과] 탭에서 행을 클릭해 다시 켜면 됩니다.

  ▸ [챕터] 탭 — 챕터 제목 띄우기
  ------------------------------------------
  영상 타임스탬프(챕터 목록)를 주면, 각 챕터가 시작할 때 그 제목을
  화면 왼쪽 위에 몇 초 동안 띄워 줍니다.

   1. 메모장에 챕터 목록을 적고 txt 로 저장합니다.
      유튜브 설명란에 쓰는 형식 그대로 붙여넣어도 됩니다.

          0:00 오프닝
          2:30 - 본론 시작
          07:10 하이라이트
          [0:12:00] 마무리 인사

      · 시각이 없는 줄(제목 줄, 빈 줄, 설명)은 알아서 건너뜁니다.
      · 시:분:초 / 분:초 둘 다 되고, - 나 [ ] 같은 기호도 괜찮습니다.
      · 예시 파일: 챕터_예시.txt

   2. [챕터] 탭 → [📄 챕터 목록 txt 선택] → 방금 만든 txt 선택
      ★ zip 과 같은 이름으로 txt 를 옆에 두면 (원본.zip / 원본.txt)
        zip 을 고를 때 자동으로 읽어옵니다.

   3. 미리보기에서 제목을 마우스로 끌어 위치를 잡고,
      표시 시간·글자 크기·색·배경·폰트를 정한 뒤 실행하면 됩니다.

  ▸ 알아두면 좋은 것
  ------------------------------------------
    · "제목 길이가 달라도 왼쪽 끝 맞추기" 를 켜두면 제목이 길든 짧든
      왼쪽 끝이 같은 자리에서 시작합니다 (길이는 어림값이라 캡컷에서
      보고 미세 조정하셔도 됩니다).
    · 다음 챕터가 표시 시간보다 빨리 오면 거기서 자동으로 끊습니다.
    · 영상 길이를 넘는 타임스탬프는 그냥 무시합니다.
    · 원래 자막과는 별도 트랙이라 자막 스타일 설정과 섞이지 않습니다.
    · 캡컷에서 불러온 뒤 글자를 고치고 싶으면 그 텍스트를 더블클릭해서
      평소 자막처럼 수정하면 됩니다.



------------------------------------------
② 인트로 넣기 — 인트로_넣기.bat
------------------------------------------
"[완성] xxx.zip" 과 인트로 영상(mp4)을 둘 다 선택해서 함께 드래그
(Ctrl 누르고 둘 다 클릭 → 같이 끌기). 순서는 상관없습니다.

씬 목록이 뜨고 두 가지를 물어봅니다:

    Position: 0:00:55:10      ← 넣을 위치
    Exact? y                  ← y 면 씬을 갈라 정확히 그 시각에 넣음

  → "[완성] xxx_인트로.zip" 생성

인트로는 배율 1.0 · 속도 1.0 으로 들어가고,
그 위에 로고·자막·배경음악·화면효과가 겹치지 않습니다.


  ▸ Position 입력 형식
  ------------------------------------------
    입력            뜻
    (엔터)          맨 앞
    end             맨 뒤
    5               5번째 씬 바로 앞
    -1              마지막 씬 바로 앞
    55.1            55.10초
    55.1s           55.10초
    55s             55초 정각
    0:55.1          0분 55.1초
    3:20            3분 20초
    1:23:45         1시간 23분 45초
    0:00:55:10      55초 10프레임 (캡컷 타임코드 그대로)

    ⚠ 숫자만 쓰면 "씬 번호"로 읽습니다.
      55 라고 치면 55초가 아니라 55번째 씬 앞입니다.
      초로 넣으려면 소수점(.) 이나 s 나 : 중 하나가 꼭 있어야 합니다.


  ▸ Exact? 가 하는 일
  ------------------------------------------
    N (기본)  가장 가까운 씬 경계로 붙입니다.
              몇 초 밀렸는지 화면에 알려줍니다.
    y         그 씬을 정확히 그 시각에서 갈라서 인트로를 끼웁니다.

    y 로 가를 때 처리되는 것:
      · 영상 소스 구간 : 앞조각 + 뒷조각으로 끊김 없이 이어짐 (속도 배율 반영)
      · 줌/이동 키프레임 : 자른 지점 값을 직선 보간으로 계산해
                          앞조각 마지막 = 뒷조각 첫 값. 화면이 튀지 않음
      · 전환 : 뒷조각으로 이동 (앞조각 → 인트로는 컷)
      · 자막·배경음악·로고·화면효과 : 인트로 앞뒤로 끊음

    ⚠ 씬을 가르면 인트로가 끝난 뒤 같은 장면이 이어서 다시 나옵니다.
      장면이 바뀌길 원하면 Exact 를 N 으로 두고 씬 경계에 넣는 쪽이 자연스럽습니다.


------------------------------------------
③ 마지막 여운 주기 — 마지막_여운주기.bat
------------------------------------------
마지막 멘트가 끝나기도 전에 화면이 뚝 끊길 때 씁니다.

zip 하나를 bat 위로 드래그 → 몇 초 더 유지할지 물어봅니다.

    음성이 끝난 뒤 몇 초 더 유지할까요? (엔터=1.0초): _

  → "[완성] xxx_여운.zip" 생성  ← 이걸 캡컷으로 불러오세요

하는 일:
  · 음성·자막 중 늦게 끝나는 쪽을 찾아서, 그보다 지정한 초만큼
    화면이 더 남도록 마지막 씬을 늘립니다.
  · 로고/워터마크도 끝까지 같이 늘려줍니다.
  · 줌/이동 모션은 원래 끝값에서 멈춘 채 유지됩니다.
    (그래서 늘어난 구간은 화면이 정지한 것처럼 보입니다)

마지막 씬을 늘리는 방식은 소재에 따라 자동으로 정해집니다:
  사진이면        그냥 늘립니다 (완전한 정지)
  영상인데 여유분 남았으면   남은 부분을 더 씁니다
  영상인데 여유분 없으면     속도를 조금 늦춰서 늘립니다
                            20% 넘게 느려지면 경고가 뜹니다

  ※ 두 번 돌려도 안전합니다. 이미 충분하면 "바꿀 게 없습니다" 하고 끝납니다.

  ▸ 먼저 확인만 하고 싶으면
      python "...\tools\hold_last.py" "완성.zip" --check
    트랙별로 언제 끝나는지 보여주고 파일은 만들지 않습니다.

[4] 명령어로 쓰는 추가 옵션
------------------------------------------
bat 대신 명령 프롬프트에서 실행하면 세부 조정이 됩니다.
(아래 경로는 이 폴더 기준입니다)

■ 인트로 검은 띠 없애기
  화면 비율이 다르면 위아래에 검은 띠가 생깁니다. 꽉 채우려면:

  python "C:\Users\user\Desktop\캡컷 올인원 효과 프로그램\tools\add_intro.py" "완성.zip" "인트로.mp4" --fill crop

■ 인트로 소리 끄기 / 로고 띄우기 / 배경음악 안 끊기

  python "C:\Users\user\Desktop\캡컷 올인원 효과 프로그램\tools\add_intro.py" "완성.zip" "인트로.mp4" --mute --logo-on-intro --bgm keep

■ 씬 목록만 보기

  python "C:\Users\user\Desktop\캡컷 올인원 효과 프로그램\tools\add_intro.py" "완성.zip" --list

■ 위치를 명령어로 바로 지정

  python "...\tools\add_intro.py" "완성.zip" "인트로.mp4" --at 0:00:55:10 --exact

■ 여운 초를 명령어로 바로 지정 / 확인만 하기

  python "C:\Users\user\Desktop\캡컷 올인원 효과 프로그램\tools\hold_last.py" "완성.zip" --hold 1.5
  python "C:\Users\user\Desktop\캡컷 올인원 효과 프로그램\tools\hold_last.py" "완성.zip" --check

■ 유료 효과가 남았는지 검사 (캡컷에서 💎 가 뜰 때)

  python "C:\Users\user\Desktop\캡컷 올인원 효과 프로그램\tools\swap_paid_fx.py" "완성.zip" --check

  --check 를 빼면 유료를 무료로 갈아끼운 새 zip("..._무료.zip")을 만듭니다.
  같은 종류에 무료 대체품이 하나도 없으면 그 효과를 아예 빼버립니다.
  (지금은 무료 필터가 없어서 "명확한 ll" 은 교체가 아니라 제거됩니다)

  유료 판정 순서:
    1) tools\swap_paid_fx.py 의 KNOWN_PAID_IDS  ← resource_id 로 판정 (가장 정확)
    2) 같은 파일의 KNOWN_PAID 이름 목록
    3) app\effects.json 의 유료 표시

  ★ 새 유료 효과가 나오면 여기서 확인할 수 있습니다:
    %LOCALAPPDATA%\CapCut\User Data\Cache\FeedbackOtherInfo.json
    캡컷이 "유료라서 막았다"고 기록해 둔 목록이라 이름 + resourceId 가 그대로 있습니다.
    그 resourceId 를 KNOWN_PAID_IDS 에 추가하면 됩니다.
    (이름은 캡컷이 바꾸는 일이 있어서 resource_id 로 관리합니다)

[5] 막힐 때
------------------------------------------
  증상                              해결
  --------------------------------  ------------------------------------
  캡컷에서 💎 Pro 표시               swap_paid_fx.py --check 로 확인
  효과 목록 수정이 안 먹힘           프로그램을 완전히 닫고 수정하세요
                                    (닫을 때 설정을 덮어씁니다)
  "Python not found"                https://www.python.org/downloads/ 에서 설치
                                    설치 중 "Add python.exe to PATH" 체크
  창이 뜨자마자 닫힘                 bat을 더블클릭하지 말고 파일을 드래그하세요
  인트로가 "미디어 분실"로 뜸        캡컷에서 그 프로젝트를 먼저 닫고 불러오세요
                                    (아래 설명 참고)
  마지막 멘트 끝나기 전에 화면 끊김  ③ 마지막_여운주기.bat 에 드래그하세요
  "인트로 영상(mp4)을 같이           zip 과 mp4 를 Ctrl 로 같이 골라
   넣어주세요"                       함께 드래그하세요


  ★ "미디어 분실" 이 뜨는 이유 ★
    캡컷은 같은 이름의 프로젝트가 이미 있으면 새로 만들지 않고
    기존 폴더에 덮어씁니다. 그 프로젝트를 열어둔 채로 불러오면
    캡컷이 예전 상태를 보고 있어서 새로 들어간 인트로만
    "미디어 분실"(빨간 클립)로 뜹니다.

    해결: 캡컷에서 그 프로젝트를 닫고 (또는 캡컷을 껐다 켜고)
          다시 불러오세요. 파일 자체는 멀쩡합니다.

    인트로_넣기.bat 은 만든 zip 을 스스로 검사해서
    [자기검사] 항목이 전부 ✔ 로 나옵니다. ✔ 인데도 분실로 뜨면
    거의 항상 위의 "열어둔 채로 불러오기" 때문입니다.

[6] 폴더 구성
------------------------------------------
  시작하기.bat            ① 효과 넣기 프로그램 실행
  인트로_넣기.bat          ② 여기로 zip + mp4 드래그
  마지막_여운주기.bat      ③ 여기로 zip 드래그
  샘플로고.png            로고 테스트용 샘플
  app\캡컷자동올인원.exe   ① 프로그램 본체
  app\effects.json        효과 카탈로그 (프로그램이 읽고 씀)
  tools\add_intro.py      ② 인트로 넣기
  tools\hold_last.py      ③ 마지막 여운 주기
  tools\swap_paid_fx.py   유료 효과 검사/교체
  tools\_capcut.py        공용 코드 (직접 실행 안 함)
  소스(수정용)\            ① 프로그램(exe)의 파이썬 원본.
                          평소엔 안 건드려도 됩니다. 프로그램 자체를
                          고칠 때만 쓰고, 안의 "빌드하기.bat" 을 누르면
                          app\캡컷자동올인원.exe 가 새로 만들어집니다.
